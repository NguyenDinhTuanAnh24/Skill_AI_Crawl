# Prompt library

Các file này là mẫu mô tả công việc. Chỉ dùng mẫu phù hợp với giai đoạn hiện tại.

| Giai đoạn | File | Dùng khi |
|---|---|---|
| Khám phá | `01-discovery.md` | Yêu cầu còn mơ hồ hoặc có nhiều hướng |
| Lập kế hoạch | `02-plan.md` | Tác vụ nhiều file/milestone |
| Thực thi | `03-implement.md` | Đã chốt scope và muốn AI code end-to-end |
| Audit dữ liệu | `04-data-audit.md` | Đổi crawler, field, công thức hoặc nhận định |
| QA giao diện | `05-ui-qa.md` | Đổi HTML/CSS/interaction |
| Release | `06-release.md` | Trước bàn giao hoặc commit |
| Review thay đổi | `07-review.md` | Muốn đánh giá diff nhưng chưa sửa code |

Thay phần `<...>` trước khi sử dụng. Xóa các dòng không liên quan; yêu cầu ngắn và đúng ngữ cảnh tốt hơn một tài liệu chứa mọi quy tắc của dự án.
