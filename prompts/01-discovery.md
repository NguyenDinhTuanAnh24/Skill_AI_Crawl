# Prompt — Discovery

```text
Tôi muốn cải thiện dự án FireAnt Stock Report với ý tưởng: <ý tưởng/yêu cầu>.

Hãy chỉ thực hiện discovery, chưa sửa file.

Đọc `SPEC.md`, `STATUS.md` và các file code trực tiếp liên quan. Trả về:
1. Vấn đề người dùng thực sự cần giải quyết.
2. Phạm vi đề xuất và phần không nên làm trong đợt này.
3. Các giả định có thể tự xác minh từ repo.
4. Tối đa 3 quyết định cần tôi chọn nếu chúng làm thay đổi sản phẩm đáng kể.
5. Acceptance criteria đo được.
6. File dự kiến thay đổi và lệnh kiểm chứng.

Không viết giải pháp chung chung; mọi đề xuất phải gắn với repo hiện tại.
```
