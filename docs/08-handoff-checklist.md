# Professional handoff checklist

## Product

- [ ] Requested outcome matches `SPEC.md`.
- [ ] No unapproved scope was added.
- [ ] CLI usage is documented.
- [ ] Generated HTML and snapshot paths are known.

## Data

- [ ] Source and retrieval timestamp are visible.
- [ ] Record counts are plausible.
- [ ] Adjustment and null-handling rules are preserved.
- [ ] No token or secret appears in artifacts.

## Quality

- [ ] `npm run verify` exits 0.
- [ ] Changed interactions were tested.
- [ ] Changed layout was visually inspected.
- [ ] Known limitations are recorded in `STATUS.md`.

## Communication

- [ ] Summary leads with the outcome.
- [ ] Changed files are linked.
- [ ] Verification evidence is stated precisely.
- [ ] Financial limitations are not hidden.
- [ ] A recommended next action is included only when useful.
